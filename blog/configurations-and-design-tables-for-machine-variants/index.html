Configurations and Design Tables for Machine Variants

One model, every length, without ten copies of the same file

Table of Contents

  • What a configuration can change
  • When to bring in a design table
  • Drawings that follow the variant

Working on something similar?

Building a family of conveyors? Share the sizes that change and the interfaces that need to stay the same.

Key takeaways

  • Keep variants in one model instead of separate copies.
  • Control dimensions through readable named variables.
  • Link part identity and drawing properties to each configuration.

The temptation, when a client asks for the 4-metre version of the 3-metre conveyor, is Save As. Two weeks later there are five files, a change has been made in three of them, and nobody is sure which is current. Configurations solve this by keeping the variants inside one document.

What a configuration can change

  • Dimension values — lengths, widths, hole spacings.
  • Suppression state of features and, in assemblies, of whole components.
  • Which configuration each child component uses.
  • Custom properties, so the part number and description follow the variant.
  • Display states, for showing the same machine with and without guarding.

Drive the dimensions through named global variables and equations rather than typing values into each configuration. "Frame_Length = 4000" reads clearly in a design table; "D3@Sketch2 = 4000" does not, and it will not survive the next person touching the sketch.

When to bring in a design table

A design table embeds a spreadsheet that lists configurations as rows and controlled values as columns. It needs Microsoft Excel installed, which is worth knowing before you build a workflow around it. For three variants, plain configurations are simpler. For a family of fifteen frame lengths, the table is far quicker to read, check and extend.

Keep the table honest

Add a column for the description and the part number, so the drawing and the bill of materials always match the row. A design table that controls geometry but not identity is how a 3-metre frame ends up on a drawing titled 4 metre.

Drawings that follow the variant

Each drawing view has a configuration property, so one drawing file can show any variant — or a separate sheet can show each. Link the title block to the configuration-specific custom properties rather than typing text, and the drawing renames itself when you switch. It is a small piece of setup that quietly removes a whole class of paperwork mistakes.
