Weldment Cut Lists a Fabricator Can Order Steel From

Folders, custom properties, and the drawing table that ties them together

Table of Contents

  • Update, then name the folders
  • Putting it on the drawing

Working on something similar?

Key takeaways

  • Update cut-list folders after geometry changes.
  • Publish useful descriptions, cut lengths, and quantities.
  • Link the drawing table to the model rather than retyping it.

Every weldment part carries a Cut List folder in the feature tree. Bodies of the same profile and length are grouped together, counted, and given a name like "Cut-List-Item3". Left alone, that is almost useless to the person ordering steel. Spend ten minutes on it and the model starts producing the ordering document itself.

Update, then name the folders

Right-click the Cut List folder and choose Update to force the grouping to refresh after a change. Then rename each folder for what it is — "SHS 50x50x3 - Cross Member", "PFC 150 - Stringer". Those names flow straight into the drawing table, so the workshop reads your words rather than an item number.

Each folder has its own properties, reached through Properties on the right-click menu. SOLIDWORKS fills several automatically from the profile and the geometry, and they are the ones worth putting on the drawing.

PropertyWhere it comes fromWhat the workshop does with it
DESCRIPTIONThe weldment profile, editable per folderKnows which section to pull from the rack
LENGTHCalculated from the bodyCuts to size; feeds the ordering total
ANGLE1 / ANGLE2End cut angles on mitred membersSets the saw
QUANTITYCount of identical bodies in the folderKnows how many to cut
MaterialThe part material, or set per bodyGrade to order
Check the lengths you are publishing

LENGTH measures the body in the model. If your weld gap trims material off an end, or a member is mitred, the cut length and the centre-line length are not the same number. Confirm with the fabricator which one their saw list expects before the drawing goes out.

Putting it on the drawing

On the drawing, Insert > Tables > Weldment Cut List places a table linked to those folders. Choose which properties become columns, save the arrangement as a table template, and reuse it on every job so each drawing reads the same way. Balloon the members in an exploded or isometric view and the fabricator can match every line of the table to a piece of steel.

  • Add a column for item marks if the workshop paints or tags each member.
  • Sort by description, so all of one section sits together for ordering.
  • Keep the table on sheet one; a cut list on a later sheet is a cut list that gets missed.
  • Re-check the table after any change to the frame — the numbers update, your notes do not.
