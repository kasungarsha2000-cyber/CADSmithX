# CADSmitX GitHub Pages preview

Test website: https://kasungarsha2000-cyber.github.io/CADSmithX/

This branch contains a GitHub Pages build with /CADSmithX/ asset paths and router basename. In Settings > Pages use Deploy from a branch, gh-pages, / (root).

The main branch preserves the exact contents of CADSmitX V1.zip for domain-root Ubuntu hosting. The original ZIP and local project have not been moved or replaced. This preview uses noindex metadata; the production canonical domain remains cadsmithx.com.
